## 为什么你的故事很重要？

<div style="max-width: 720px; margin: 0 auto;" markdown="1">

对于每一个正在州民中读书的学弟学妹来说：

- 他们不知道某个专业**真正学什么**
- 他们不知道某个大学**真实的校园生活**是怎样的
- 他们不知道某个城市**是否适合自己**
- 他们不知道**志愿填报有哪些坑**

而这些答案，**不在招生简章里，只在你的亲身经历里。**

你花 30 分钟写下的分享，可能会影响一个学弟/学妹未来四年甚至更久的选择。

</div>

<!-- 关于 Markdown -->
## 关于 Markdown

> **请不要被「代码」、「语法」这些词吓倒！**

飞跃手册使用 Markdown 撰写。Markdown 是一个简单到可以在几分钟内学会的格式——它让你用纯文字就能写出有标题、有列表、有强调效果的文档。

如果你从来没接触过 Markdown，可以参考：

- [**Markdown 基本语法**](https://markdown.com.cn/basic-syntax/) — 10 分钟就能看完
- [**我们已有的案例文件**](https://github.com/AndrewLong7/zhouminzhong-feiyue/tree/main/docs/cases) — 看看别人怎么写，照着改就行
- [**投稿模板**](#template) — 直接复制粘贴，改掉占位符即可

**当然，如果你暂时不想学 Markdown，也完全没有关系**——直接用纯文字写邮件投稿，排版我们帮你处理。

不想填问卷？直接发邮件即可。

### 🐙 方式三：GitHub PR

熟悉 GitHub？直接提交 Pull Request。

1. 在 `docs/cases/` 对应年份文件夹中新建 `.md` 文件

3. 提交 Pull Request

文件名格式：`你的化名-学校.md`，如 `xiaoxi-pku.md`

适合：
- 有 GitHub 使用经验的同学
- 希望体验开源协作

## 📝 投稿模板 {#template}

> **不用担心格式！** 把以下内容复制下来，用纯文字填写后发送即可。排版和格式由我们来处理。

<div style="background: #F8F7F2; border: 1px solid #E8E6E1; border-radius: 16px; padding: 32px; margin: 24px 0;" markdown="1">

```
化名：（用于展示的名字，支持完全匿名）
毕业届数：如 2025 届
高考分数：如 642 分
全省位次：如 全省第 2851 名
选科组合：如 物理 + 化学 + 生物
录取院校：如 中南大学
录取专业：如 临床医学（八年制）
所在城市：如 长沙
联系方式：微信 / QQ / 邮箱（选填，不会公开）

---

一、我为什么选择这个学校/专业？

（请写下你真实的考虑过程：是因为兴趣？分数合适？家庭影响？
还是某个偶然的原因？越真实越好。）

二、大学真实体验

1. 学习压力：
（课业负担如何？和高中相比最大的不同是什么？）

2. 校园氛围：
（学校的整体氛围是卷、是自由、是多元、还是有其他特点？）

3. 城市感受：
（这个城市给你什么感觉？气候、饮食、节奏适合湘西来的学生吗？）

4. 宿舍与生活：
（住宿条件、生活成本如何？）

5. 资源与机会：
（学校提供了哪些资源？实习、科研、社团、交换、奖学金、助学金、校友资源等？）

6. 社交与成长：
（人际关系、同辈压力、个人成长方面有什么感受？）

三、我踩过的坑

（这是非常重要的模块。请分享你在志愿填报、大学适应、
专业选择等方面走弯路的地方，帮助后来者避开。）

四、写给后来者的一句话

（请为未来的州民中学子留下一句话。可长可短。）

五、标签

请从下面选几个适合你的标签：
985 / 211 / 双一流 / 港澳 / 海外
理工 / 文科 / 医学 / 商科
跨省 / 本省
你的城市名
你的专业名
```

<!-- 投稿须知 -->
## 投稿须知

<div class="fy-contribute-steps" markdown="1">

1. ### 匿名机制
   你可以使用**化名**或**完全匿名**。我们尊重每一位分享者的隐私。  
   如果你不希望暴露任何身份信息，请在投稿时注明。

2. ### 内容审核
   所有投稿会经过简单审核后发布。审核标准：
   - 内容真实、具体
   - 不含人身攻击或敏感信息
   - 对学弟学妹有参考价值

3. ### 持续更新
   投稿发布后，你可以随时联系我们修改或补充内容。  
   如果你在大学的不同阶段有新的感悟，欢迎更新你的案例。

4. ### 版权说明
   你保留你故事的所有权利。  
   你授权本网站以非商业目的展示你的投稿内容。

</div>
