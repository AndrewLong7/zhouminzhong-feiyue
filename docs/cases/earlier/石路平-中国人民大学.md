## 应届生去向

首先，我欢迎对人文有学习兴趣的考生联系我，在进入这个领域之前，我先简要提及并不致力于人文，仅作为跳板的一些基本信息（可能会有变动，仅个人了解信息），我没法告知更多。
1. 保研率20-30%之间，学院会尽量向30%去趋近。转专业方案是大一学分绩10%以内提出申请。
2. 考研方向本专业为主。
3. 就业，就业不占优势，在马克思主义哲学专业对于思政领域的就业有部分优势。
4. 对外国哲学有深造需求的会出国留学，但是本校相对于同水平学校此方面不占优势（类比复旦大学、武汉大学、中山大学等）。

接下来的内容有关人文领域有兴趣的考生，欢迎这部分考生联系我，我会尽我所能给出信息。
我的本科和硕士在中国人民大学哲学院，学习和研究方向主要是外国哲学，现在于法国攻读哲学博士学位，方向是当代法国哲学。
我能提供的信息涵盖以人文与学术为目标的本科规划、保研准备、博士申请（含国家公派计划说明）。
