    投稿指南¶

    你的经验，是后来者最珍贵的礼物。
    分享你的故事，帮助更多州民中人看见更大的世界。

    为什么你的故事很重要？¶

    对于每一个正在州民中读书的学弟学妹来说：

    • 他们不知道某个专业真正学什么
    • 他们不知道某个大学真实的校园生活是怎样的
    • 他们不知道某个城市是否适合自己
    • 他们不知道志愿填报有哪些坑

    而这些答案，不在招生简章里，只在你的亲身经历里。

    你花 30 分钟写下的分享，可能会影响一个学弟/学妹未来四年甚至更久的选择。

    两种投稿方式¶

    📧 方式一：邮箱投稿¶

    发送邮件至 u3638259@hku.hk

    主题格式：[投稿] 你的化名 - 录取院校

    将你的案例内容（参考下方模板）写在邮件正文中，或作为附件发送。

    适合： - 不熟悉 GitHub 的同学 - 希望完全匿名的投稿 - 快速投稿

    🐙 方式二：GitHub PR 投稿¶

    1. Fork 我们的 GitHub 仓库
    2. 在 docs/cases/ 下对应年份文件夹中新建 .md 文件
    3. 按下方模板填写内容
    4. 提交 Pull Request

    适合： - 熟悉 GitHub 的同学 - 希望参与开源协作 - 持续贡献

    投稿须知¶

    1. 匿名机制¶

      你可以使用化名或完全匿名。我们尊重每一位分享者的隐私。
      如果你不希望暴露任何身份信息，请在投稿时注明。

    2. 内容审核¶

      所有投稿会经过简单审核后发布。审核标准：

    3. 内容真实、具体
    4. 不含人身攻击或敏感信息

    5. 对学弟学妹有参考价值

    6. 持续更新¶

      投稿发布后，你可以随时联系我们修改或补充内容。
      如果你在大学的不同阶段有新的感悟，欢迎更新你的案例。

    7. 版权说明¶

      你保留你故事的所有权利。
      你授权本网站以非商业目的展示你的投稿内容。
